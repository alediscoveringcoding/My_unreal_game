# My_unreal_game
My game made in unreal to practice game dev

Adventure Mania
Adventure Mania is a single-player platform game. The primary goal of the game is to collect all the stars within a level without losing the character's lives.


Technical Features
Developed entirely in Unreal Engine 5 utilizing visual programming through Blueprints.


Complete menu system including a Main Menu, Pause Menu, Game Over screen, and an active HUD interface.


Player gameplay mechanics featuring jumping, sword attacks, collision detection, and respawning at the last safe spot.

Enemy AI implemented with patrol logic (Wander) and player tracking (Chase).


Interactable Elements
Collectibles: Coins, stars, and hearts for health restoration.


Obstacles and mechanisms: Spike traps and spring pads.

Animation and Design
Animation system based on a State Machine for smooth transitions between Idle, Run, Jump, and Land.

Dynamic weapon equipping using a WeaponSocket attached to the character's skeleton.

Prototype level designed with platforms, vegetation, and specific spawn points for objects.
